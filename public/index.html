    O que é

    Painel independente e de código aberto que verifica a disponibilidade dos sistemas nacionais de saúde pública: e-SUS APS, CADSUS, RNDS, Gov.br e portais de gestão federal. Não tem vínculo com o Ministério da Saúde nem com o DATASUS.

    Como os dados trafegam

    1. Unidade de Saúde. O atendimento é registrado no e-SUS PEC ou em um prontuário próprio.
    2. Barramentos em tempo real. O prontuário consulta pacientes no SOA-CADSUS (SOAP) e envia vacinas à RNDS (HL7 FHIR).
    3. Centralizador Nacional. Os lotes de produção são transmitidos para esusab.saude.gov.br.
    4. Base federal. O SISAB e o e-Gestor APS validam as fichas e calculam os indicadores de cofinanciamento.

    Por que separar API e portal

    O portal web do CADSUS (cadastro.saude.gov.br/novocartao/) pode estar fora do ar enquanto o WebService usado pelos prontuários (servicos.saude.gov.br/cadsus/…?wsdl) continua respondendo. Monitorar os dois mostra se a falha é só na tela do navegador ou se de fato impede o atendimento.

    Monitorar serviços locais

    Inclua a instância do e-SUS PEC do município, bancos de dados ou portais estaduais no config.json. As alterações valem no próximo reinício do servidor.

    {
  "customEndpoints": [
    {
      "id": "pec-local",
      "name": "e-SUS PEC Local",
      "shortName": "PEC Local",
      "layer": "municipal_local",
      "layerLabel": "Instância Municipal",
      "protocol": "TCP / PostgreSQL",
      "type": "Banco de Dados",
      "url": "tcp://192.168.1.100:5433",
      "tcpHost": "192.168.1.100",
      "tcpPort": 5433,
      "expectedCodes": [200],
      "warnLatencyMs": 100,
      "enabled": true
    }
  ]
}

    API

    GET /api/status devolve o último snapshot. GET /api/probe/<id> verifica um serviço sob demanda.
